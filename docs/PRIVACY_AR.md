# Chico Admins 1.3 — البيانات اللازمة والخصوصية

هذا الإصدار يعرض أسماء الإداريين داخل اللعبة وبيانات عمل الفريق فقط. لا يفرض أسماء وهمية بدل أسمائهم الإدارية. لا توجد حقول لبريد حقيقي أو هاتف أو اسم قانوني أو عنوان أو تاريخ ميلاد أو موقع أو Discord ID. لا يقرأ التطبيق IP أو User-Agent لتحديد المحاولات أو حفظ الجلسة. أزيلت CAPTCHA الخارجية؛ لا توجد تحليلات أو خطوط أو أدوات تتبع من طرف ثالث في واجهة التطبيق.

| البيانات | الغرض | ما يحفظ |
|---|---|---|
| Username | الدخول | معرف مستعار يقدر صاحبه تغييره بعد التحقق |
| كلمة المرور | المصادقة | يتولاها مزود Auth؛ لا يسجلها التطبيق كنص |
| الجلسة | حفظ الدخول وإلغاؤه | رمز عشوائي في Cookie HttpOnly، وبصمته ورموز Auth مشفرة ومعرف تقني وأوقات تشغيل |
| اسم العرض | عرض عضو الفريق | اسم الإداري داخل اللعبة، يحدده المسؤول المخول |
| الرتبة والانضمام | الصلاحيات والأرصدة | رتبة اللعبة وتاريخ الانضمام للفريق، وليس تاريخ ميلاد |
| الصورة الرمزية | صورة يختارها العضو | قص إلى PNG ثابت، إزالة EXIF والنصوص والاسم الأصلي؛ لا نطلب صورة شخصية |
| رابط Discord | ربط طلب إجازة أوتبرير برسالته | رابط الرسالة فقط؛ لا نطلب معرف حساب Discord أو نقرأ الرسالة آليًا |
| النقاط | الأداء والمكافآت | نسخة توزيع الأوزان والتعديل والسبب والسجل |
| السجلات | عمل الفريق | التقارير والمناوبات والطلبات والوقائع ومصادرها التشغيلية |
| التدقيق | تفسير القرار | المعرف واسم الإداري والقرار والتاريخ والقيم اللازمة |
| الاستعادة | إتمام عملية واحدة | بصمة الرمز وكلمة جديدة مشفرة مؤقتًا؛ يمحى التشفير عند النجاح |

الخادم لا يحتفظ بمحتوى مصنف Excel الكامل: ينشئ مصدر CSV من الأعمدة المسموحة، بعد التحقق، مع اسم ملف محايد. ممنوع إدخال معلومات شخصية في أسباب القرارات أو المصادر النصية؛ تكتب واقعة العمل ورقمها التشغيلي فقط. لا يمكن تحويل نص حر إلى ضمان آلي بأنه لا يحتوي معلومة شخصية كتبها شخص بنفسه.

سياسات الحسابات والملفات تفرض العزل على قاعدة البيانات، وليس إخفاء الأزرار فقط. النشر لرتبة Moderator فما فوق؛ Helper وSN.Helper لا ينشران حتى مع ملكية الموقع. الإدارة والاعتماد لصاحب الموقع وResponsible فقط. العضو يشوف تفاصيله وحده، والتوب لا يحتوي تذاكر أو ساعات أو تقييم الزملاء. الاسم الظاهر لا يغير Username.

تعطيل الحساب يوقف الوصول ويلغي الجلسات ويحفظ أثر العمل. لا يعد حذفًا للتاريخ ولا فصلًا من اللعبة. إعادة التفعيل تحتاج دخولًا جديدًا؛ الرفض يعود إلى انتظار مراجعة، ولا يتجاوز الاعتماد.

حذف جمع IP من التطبيق لا يغير سجلات اتصال مزود الاستضافة أو Auth؛ يراجع المشغل إعدادات احتفاظ تلك الخدمات وصلاحياتها. مصادر 1.0 القديمة تُحجر حتى مراجعتها؛ الحجر يمنع الوصول ولا يزيل البايتات بنفسه. لم تكن قاعدة إنتاج أو مصادر إدارية حقيقية مربوطة بهذه النسخة أثناء البناء.

صور الأعضاء في Bucket خاص، ولا تُستخدم خدمة صور خارجية. يصل العضو إلى صورته وصور التوب فقط؛ Owner وResponsible يصلان إلى صور الفريق. الرفع المباشر إلى Storage ممنوع، ويجب المرور بخادم التنقية. لا تحفظ ملفات الصور الأصلية ولا بياناتها الوصفية.

تنبيهات الحساب محفوظة لصاحبها. إشعارات الإدارة تخضع لصلاحية Owner/Responsible الحالية عند القراءة، ولا تبقى مكشوفة لمن تغيرت رتبته. النصوص لا تنقل إحصائيات الزملاء أوبيانات التدقيق الخام، ولا تحتوي أسرار استعادة. الدخول وتغيير كلمة المرور لهما تنبيهات بلا بصمة جهاز أوعنوان IP.

لا توجد بيانات أعضاء تجريبية في واجهات الموقع. بيانات fixtures الاصطناعية داخل مجلد الاختبارات فقط. صورة واجهة OneState ملف محلي من مصدر اللعبة الرسمي، ولا يرسل المتصفح طلب صورة إلى طرف خارجي.
