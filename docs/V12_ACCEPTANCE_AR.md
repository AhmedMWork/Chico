# Chico Admins 1.2 — مطابقة المتطلبات

| طلب المستخدم | التنفيذ |
|---|---|
| الإدارة لصاحب الموقع وResponsible | حراس قاعدة البيانات والواجهة والاستيراد؛ Administrator بلا إدارة حتى مع منح قديمة |
| خصوصية إحصائيات الزملاء | RLS وDTO: تفاصيل العضو نفسه أوالإدارة فقط؛ منشئ تقرير قديم لا يحتفظ بحق قراءة زميله |
| التوب في الرئيسية | ثلاثة بكل مجموعة؛ اسم مستعار ورتبة وقت القياس ونقاط وصورة فقط |
| فصل الهيلبر والمودريتور | قائمتان مستقلتان، مع SN.Helper داخل الهيلبر، دون كشف إحصائيات الزملاء |
| نقاط يعتمد عليها الأداء | أوزان قابلة للتعديل، سياسات محفوظة، مكافأة/خصم بسبب وإلغاء يحفظ التاريخ |
| سجل لكل عضو | أداء وطلبات وقرارات وتغييرات الملف؛ العضو يرى سجله والإدارة تختار العضو |
| الطلب على الموقع وDiscord | رابط رسالة Discord مطلوب؛ لا إرسال تلقائي أوطلب معرف حساب Discord |
| الرصيد لا ينقص قبل القبول | المعلق لا يخصم؛ القبول يفحص الرصيد ويخصم مرة واحدة |
| التجديد أول الشهر | حساب مستقل لكل شهر بتوقيت السعودية دون حذف الطلبات السابقة |
| كلمة المرور6 | التسجيل والاستعادة والتغيير؛ إعداد Auth على6 مطلوب وقت التفعيل |
| تعديلات الملف | صورة رمزية وUsername وكلمة المرور؛ الاسم الظاهر والرتبة للإدارة |
| تغيير اليوزر صالح للدخول | تحديث الاسم وتطبيعه بصورة ذرية؛ الجديد يعمل والقديم يتوقف والتكرار مرفوض |
| لا معلومات شخصية عن الإداريين | حقول مستعارة وتشغيلية، صور اختيارية منقاة، لا بريد/هاتف/اسم حقيقي/IP/User-Agent |
| الهوية والنصوص | Chico Admins / General Team، إزالة العبارة المرفوضة وJSON التقني من واجهة السجل |
| الشكل والصور والحركة | الأسود والذهبي، صورة المدينة المحسنة، شارات الرتب والصور الرمزية وحالات تفاعل وReduce Motion |
| الموبايل والتابلت | شبكات متجاوبة وقائمة وحوارات ومساحات آمنة؛ لم يُجر قبول بصري على جهاز فعلي |
| ربط مشروع Chico | URL والمفتاح العام وأسرار الجلسة مجهزة؛ Auth public settings=200؛ SQL/AuthAdmin ينتظران إعداد الخادم |
| GitHub | حزمة جاهزة؛ لم تُرفع إلىAhmedMWork/Chico لأن صلاحية الاتصال push=false |
| Safari الفعلي | سكربت أصلي وworkflow يدوي جاهزان، لم ينفذا لعدم وجودMac/iPhone وصلاحيةGitHub |

**حدود الإصدار:** لا تعد نسخة الحسابات الحقيقية مفعّلة قبل تطبيق17Migration وإضافة مفتاح الخادم وتهيئة المالك وإجراء قبول حي. لا توجد رسائلDiscord آلية أوتغيير تلقائي لصلاحيات اللعبة. جميع بيانات `/preview` وهمية ومعزولة عن الإنتاج.
