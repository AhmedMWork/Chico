|---|---|---|

| A08 | إزالة تحديد العميل عبر IP | اختبار عدم قراءة الترويسات ومسح buckets القديمة |

| A12 | إعادة المرفوض إلى انتظار مراجعة | SQL؛ لا تفعيل مباشر للمرفوض |
| A13 | مهمة واحدة لثلاثة توبيخات مع مصادرها | SQL الإنشاء والسحب دون فصل آلي |
| A14 | الوقت جزء من مقارنة التقرير | اختبار تصحيح أسبوعي دون تغيير الأرقام |

| A16 | رصيد الشهر الحالي ولقطة سياسة لكل طلب جديد | SQL ووسوم الفترة في الواجهة |
| A17 | ربط العضو لا يعدل سجله، وحقول معطلة وخيارات مناسبة | SQL يحفظ الاسم والرتبة والتاريخ |
| A18 | فاعل وهدف وعملية عربية وقيم قبل/بعد وصفحات | AuditPanel وRPC أقدم السجلات |
| A19 | إعادة المصدر وفق البصمة ومسار حتمي وتنظيف مرحلي | SQL reuse/cleanup؛ التخزين الحي غير مختبر |
| A20 | ورقة وأرقام خام ومهام ونوع أسبوعي وخطة فروق | اختبارات المصدر والخطة، ومعالج مراجعة متعدد المراحل |

تحسينات العرض: الأسود والذهب المعتمدان، ثلاثة مستويات سطح، تكبير العربية واللمس، بطاقات الهاتف، حواف iPhone الآمنة، تنقل يرجع بالقسم والفترة، تهدئة الحركة عند الطلب، وتحسين أصول المدينة وتنظيف قواعد الأبيض والاعتماديات غير المستخدمة. المعاينة توضيحية للقراءة فقط.

بوابة الإعداد الحي لم تغلق: متغيرات الخادم وقاعدة المستخدم غير مهيأة. بوابة الجهاز الفعلي لم تغلق لغياب أداة المتصفح المعتمدة. سجل هذه الحدود عند تقرير قبول التشغيل، ولا تعتمد نجاح بناء المصدر كاختبار إنتاج.
