# Chico Admins 1.3 — تحقق المصدر

الفحوص تستخدم Node وPostgreSQL داخل PGlite وReact SSR، دون بيانات إنتاج. تقرير التسليم خارج المصدر يذكر SHA والنتائج النهائية.

- المخطط: تطبيق جميع ملفات 001–019، مع استمرار اختبار ترقية 1.0 بسجلات قديمة.
- الملكية: حجز الاسم، دعم المسافات، منع الزائر من إجراءات الخادم، منع مالك ثان، وعدم ترقية حساب باسم مشابه.
- تجهيز Owner: رفض المالك القائم، حفظ هوية العملية قبل Auth، استئناف الهوية نفسها، تسوية نتيجة RPC المؤكدة، ومنع حذف هوية إذا كانت النتيجة غير مؤكدة.
- الإشعارات: أحداث بعد المعاملة فقط، قراءة حسب الحساب والصلاحية الحالية، إخفاء إشعارات الإدارة بعد خفض الرتبة، عداد وقراءة الكل وصفحات بترتيب ثابت.
- خصوصية الإشعارات: لا قيم تقرير أوأسرار استعادة في النصوص أوالمفاتيح؛ لا إشعار شبح بعد rollback؛ إكمال كلمة المرور المتكرر لا يكرر التنبيه.
- الانحدار: Owner/Responsible فقط للإدارة، منع Helper من النشر، خصوصية الزملاء، النقاط وسياساتها التاريخية، الإجازة والموافقة والتجديد الشهري، التعطيل والاستعادة والجلسات والاستيراد والصور المنقاة.
- المصدر والواجهات: لا fixtures في الصفحات العامة، تحويل preview/setup للدخول، عرض React لكل المساحات، TypeScript، بناء Next.js وبناء Sites.

نجاح البناء لا يثبت المظهر على متصفح فعلي. لم ينفذ Safari أوiPhone/iPad أواختبار متصفح آخر بهذه البيئة، ولا إنشاء Owner حي أواستعادة سحابية أواختبار ضغط متعدد اتصالات PostgreSQL. سكربت Safari فُحص نحويًا فقط. سكربت تحديث Windows لم يُشغّل على Windows.

فحص الاتصال العام السابق للمشروع أعاد Auth settings=200 وREST root=401 لغياب مفتاح الخادم. هذا لا يثبت تطبيق أي SQL أوامتلاك صلاحية الإدارة. لم تُكتب بيانات إلى قاعدة المستخدم. الاتصال المتاح هنا إلى GitHub لا يملك push؛ التسليم بحزمة مصدر كاملة للمستخدم.
