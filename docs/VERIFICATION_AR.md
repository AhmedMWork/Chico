# Chico Admins 1.2 — تحقق المصدر

الفحوص المحلية تعمل على PostgreSQL داخل PGlite وNode، ولا تستخدم قاعدة الإداريين الحقيقية. تقرير التسليم المرفق خارج المصدر يثبت SHA والنتائج النهائية.

- SQL: إنشاء مخطط كامل وترقية قاعدة1.0 ذات بيانات قديمة حتى17Migration.
- الصلاحيات: Owner وResponsible، منع Administrator ومنح قديمة، حماية المالك ومنعHelper من النشر حتى لوOwner.
- الخصوصية: RLS وDTO للتقارير والسجل والصور والملفات؛ التوب لا يحتوي إحصائيات تفصيلية.
- النقاط: سقف نسب الأداء، قواعد العدد اليومي والملخص الأسبوعي، سياسات محفوظة وتعديل/إلغاء بسبب ورتبة تاريخية صحيحة.
- الطلبات: رابطDiscord، طلب الذات فقط، لا خصم عند الإرسال، منع صرف زائد عند القبول، تجديد شهري مع التاريخ، فترة العضو الجديد دون اعتماد على ترتيب الموافقات.
- الملف: ستة أحرف، تغيير وتفردUsername وتوقف القديم، تنقيةPNG منEXIF والنصوص، منع الرفع المباشر وتجاوزالأبعاد والملفاتالتالفة والمتحركة.
- الانحدار: التعطيل وإعادة التفعيل والاستعادة وحجب الحوادث الملتبسة والجلسات والاستيراد الذري وتصحيحالإحصائيات والأهداف التاريخية والانضباط.
- الواجهة: عرض React على الخادم لكل المساحات، RTL وأسماء مفهومة ومنع واجهة الإدارة للحساب العادي، وفحصTypeScript وبناءNext.js وSites.

تحقق الاتصال العام `/auth/v1/settings`=200. `/rest/v1/`=401 برسالة Secret API key required؛ هذا لا يعني تطبيق المخطط أوامتلاك صلاحية إدارة. لم تُكتب بيانات أوتُنشأ حسابات على مشروع المستخدم.

لم ينفذ: متصفح فعلي أوSafari/iPhone، دخولAuth حي، استعادة نسخة سحابية أوضغط متزامن متعدد اتصالاتPostgreSQL. اختبارات القفل تتحقق من المسارات والمعاملات داخلPGlite؛ لا تثبت تحمّل الإنتاج. GitHubالمستهدف بلاصلاحيةكتابة، لذلكworkflowSafari لم يشغّل.
