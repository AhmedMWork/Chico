# Chico Admins 1.3 — متطلبات التعديل

| الطلب | التنفيذ |
|---|---|
| هل أي شخص يقدر يدخل مالك؟ | حذف واجهة Owner التجريبية وإغلاق Bootstrap من المتصفح. الملكية من إجراء خادم مخول فقط، ومالك واحد بقفل قاعدة البيانات. |
| Owner Chico | دعم المسافة في Username، وحجز الاسم من التسجيل العام. أداة تجهيز محلية دون كلمة مرور ثابتة. الحساب الحقيقي لم يُنشأ بعد. |
| أسماء الإداريين | يظهر اسم الإداري داخل اللعبة بدل أسماء عضو ألف/باء. الاسم الظاهر للمسؤول، وUsername مستقل للدخول. |
| لا معلومات وهمية | بيانات الاختبار موجودة داخل tests فقط؛ لا Route عام يعرضها، ولا بيانات بديلة عند تعطل الاتصال. الحالات الفارغة تنتظر بيانات فعلية. |
| ألوان وحركة | هوية ذهبية مع أحمر وأزرق وبنفسجي وأخضر للحالات والرتب، إطارات زاوية وحركة تفاعل، واحترام Reduce Motion. |
| صور اللعبة | استبدال المدينة القديمة بشخصيات OneState الرسمية، مع توثيق المصدر وشعارات Chico/OneState. |
| إشعارات ملفتة | جرس بهالة وعدّاد، رسالة عند وصول جديد، صفحة محفوظة وقراءة فردية/الكل، وتحديث كل 15 ثانية أثناء فتح الصفحة. |
| خصوصية الإشعارات | نصوص تشغيلية مختصرة دون تفاصيل أداء زميل؛ صلاحية الإدارة تُراجع عند القراءة وبعد تغيير الرتبة. |
| الهاتف والتابلت | CSS مرن ومساحة آمنة وأهداف لمس، مع إصلاح تخطيط الدخول تحت 960px. Safari/iPhone الفعلي ما زال بحاجة اختبار على Apple. |
| منع تكرار أخطاء الرفع | حزمة مصدر كاملة، سكربت تحديث Windows يحافظ على Git والبيئة، وإصلاح اعتماد Vite على ملف hosting المخفي. |

هذه مطابقة تنفيذ المصدر، وليست إثبات تشغيل قاعدة المستخدم. يلزم تطبيق Migration 018 و019 على قاعدة 1.2 المكتملة، وإكمال مفتاح الخادم في الاستضافة، وتشغيل أداة المالك. لا تطبق ترقيتين على قاعدة لم تُجهز بملفات 001–017.
