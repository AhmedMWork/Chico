# Chico Admins 1.2 · General Team

نظام إدارة فريق عربي بالشكل الأسود والذهبي، بواجهات للموبايل والتابلت والكمبيوتر.

الإدارة الكاملة لصاحب الموقع وResponsible فقط. كل عضو يشوف إحصائياته وسجله، والتوب يعرض الأسماء والنقاط فقط. Helper وSN.Helper لا ينشران إحصائيات حتى مع ملكية الموقع. التسجيل Username وكلمة مرور من 6 حروف، ثم انتظار الاعتماد.

الإصدار يضيف نقاط أداء قابلة للضبط، سجلًا محفوظًا لكل عضو، طلبات إجازة وتبرير برابط رسالة Discord، رصيدًا يُخصم بعد الموافقة ويتجدد أول الشهر، وصورة رمزية وتغيير اليوزر وكلمة المرور. الاسم الظاهر يحدده المسؤول. لا توجد حقول معلومات شخصية أو تتبع من التطبيق.

المصدر منفذ ومختبر. التشغيل بالحسابات الحقيقية يحتاج تطبيق SQL وإكمال أسرار الخادم. تم التحقق من استجابة خدمة المشروع المرسل، ولم تُطبّق Migrations على قاعدة المستخدم. `/preview` يحتوي أسماء وأرقامًا تجريبية فقط.

## تشغيل المصدر

Node.js 24 وpnpm 11.25.0:

```sh
corepack enable
pnpm install --frozen-lockfile
pnpm run env:setup
```

أكمل `.env.local` على جهاز المشغل وفق الدليل، دون مشاركته. ثم:

```sh
pnpm run env:check
pnpm run typecheck
pnpm test
pnpm run build:vercel
pnpm run dev:vercel
```

`env:setup` يولد مفاتيح الخادم دون طباعتها ولا يغير ملفًا قائمًا. `env:check` يتحقق من الصيغة فقط. المصدر لا يحتوي كلمة مرور افتراضية أو أسرارًا أو ملفات الإداريين الأصلية.

المصدر يدعم Next.js على استضافة Node أو إعداد `vercel.json` المرفق، ومسار Sites/Vinext الخاص بـ`pnpm run build`. إعداد المزود يدوي ولا يتطلب أي إضافة مرفوضة. الحزمة القابلة للنقل تُنتج من Git نظيف بـ`pnpm run release:zip`.

اختبار Safari الحقيقي وiPhone الحقيقي مجهز ولم يُشغّل؛ يحتاج Mac وجهازًا متصلًا. GitHub المستهدف AhmedMWork/Chico، والاتصال الحالي لا يملك صلاحية كتابة، لذلك لم يُدفع إليه المصدر أو تشغّل Actions. نقاط المصدر محفوظة في مستودع Site نفسه.
