# Chico Admins 1.3 · General Team

نظام إدارة الفريق بواجهة عربية RTL للموبايل والتابلت والكمبيوتر. الإدارة الكاملة للـOwner وResponsible فقط. كل إداري يشوف أداءه وسجله؛ التوب يعرض اسم الإداري والنقاط، مع فصل Helper عن Moderator. Helper وSN.Helper لا ينشران الإحصائيات، حتى مع ملكية الموقع.

النسخة 1.3 تزيل العرض التجريبي والبيانات الوهمية من الموقع، وتعرض أسماء الإداريين الفعلية داخل اللعبة. ألوان حالات ورتب متعددة، صور من OneState، تنبيهات محفوظة بعدّاد مضيء، وتحديث تلقائي كل 15 ثانية أثناء فتح الموقع. صفحات `/preview` و`/setup` تحول إلى الدخول الفعلي؛ لا توجد ملكية من المتصفح أو لمجرد أن الحساب أول مسجل.

الحسابات Username وكلمة مرور من 6 أحرف، مع حفظ الدخول واعتماد المسؤول بعد التسجيل. اسم `Owner Chico` محجوز للتجهيز المحمي على الخادم؛ كلمة المرور تُدخل محليًا ولا تُرفق بالمصدر. النقاط والطلبات والأرصدة والسجلات والصور الرمزية موجودة دون طلب بيانات شخصية.

التشغيل الحقيقي يحتاج تطبيق SQL وإكمال مفتاح Supabase الخادمي. لم يتم إنشاء حساب المالك أو تعديل قاعدة المستخدم بهذه الجلسة. لا يوجد بديل تجريبي عند عدم اكتمال الاتصال؛ تظهر حالة تجهيز واضحة.

## التشغيل

Node.js 24 وpnpm 11.25.0:

```sh
corepack enable
pnpm install --frozen-lockfile
pnpm run env:setup
```

أكمل `.env.local` حسب دليل التشغيل، ثم:

```sh
pnpm run env:check
pnpm run typecheck
pnpm test
pnpm run build:vercel
pnpm run dev:vercel
```

النشر على Vercel يستخدم `vercel.json` وNext.js App Router من جذر المشروع الذي يحتوي `app/`. إعداد Vite لا يعتمد على استيراد ملف Sites المخفي وقت فحص TypeScript. مسار Sites يبقى مدعومًا بـ`pnpm run build` مع هوية المشروع نفسها. لا توجد أسرار أو كلمات مرور افتراضية أو ملفات الإداريين الأصلية في الحزمة.

لتحديث النسخة الموجودة على Windows استخدم `scripts/update-from-release.ps1` من مجلد الحزمة الجديدة؛ يحافظ على `.git` وملفات البيئة، وينقل المصدر الكامل بما فيه الملفات المخفية. راجع الفروق قبل commit وpush. فحص Safari/iPhone الفعلي لم يُنفذ؛ الأدوات والدليل جاهزان.
